# NEXA

NEXA is a modern social network focused on a clean, dark, mobile-first experience.

## Stage 0

The foundation includes:

- Next.js + TypeScript
- mobile-first responsive shell
- dark neon NEXA design system
- home feed prototype
- navigation placeholders
- clean base for future auth, profiles, media, messaging and database layers

## Run locally

```bash
npm install
npm run dev
```

## Product direction

NEXA is designed as a real social network, not a copy of an existing platform. The visual identity uses near-black surfaces, restrained red/blue neon accents, glass-like panels and subtle grain/glitch details. User-generated media remains the focus; there are no built-in fictional characters in the social network UI.
